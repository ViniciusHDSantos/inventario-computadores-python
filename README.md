# Sistema de Inventário de Computadores

Sistema de inventário desenvolvido em Python para cadastro e controle de computadores.

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em Python, com o objetivo de praticar conceitos de lógica de programação, estruturas de dados, validação de informações e manipulação de arquivos CSV.

O sistema permite cadastrar computadores, listar os equipamentos cadastrados, salvar o inventário em um arquivo CSV e realizar a leitura dos dados salvos.

## Funcionalidades

- Cadastro de computadores
- Listagem dos computadores cadastrados
- Validação de campos obrigatórios
- Validação da memória em formato numérico
- Verificação de patrimônio duplicado
- Salvamento do inventário em CSV
- Leitura do inventário salvo
- Menu interativo

## Tecnologias utilizadas

- Python
- CSV

## Conceitos praticados

- Variáveis
- Listas
- Dicionários
- Estruturas condicionais
- Estruturas de repetição
- `try/except`
- Validação de entrada
- Manipulação de arquivos
- Leitura e escrita de arquivos CSV

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `inventario.py`.
4. Utilize o menu apresentado no terminal.

## O que aprendi

Durante o desenvolvimento deste projeto, pratiquei a utilização de listas e dicionários para armazenar informações, estruturas de repetição e condicionais para controlar o funcionamento do sistema, tratamento de erros com `try/except` e manipulação de arquivos CSV para armazenar e consultar os dados do inventário.
